# Video captions

When a visitor opens a YouTube video in the pop-up player, the site looks for a caption file here named after the video ID and, if it finds one, shows the captions in a side pane next to the video. The current line is highlighted as the video plays, and clicking a line jumps to that moment. If there is no file, the pop-up shows only the video.

| Video | File |
| --- | --- |
| VeriSure AI demo | `aKOF6jhtvdI.vtt` |
| VibeSense demo | `rObEcmknkh8.vtt` |
| DeepSpeak demo | `WxJKg3CW3MM.vtt` |

Both WebVTT (`.vtt`) and SubRip (`.srt` contents saved as `.vtt`) work. To get one for your own video: YouTube Studio, Subtitles, open the video, the three dots next to the language, Download.

The player is told not to draw captions on the video. A viewer who has always-on captions turned on in their own YouTube account may still see them there.
