Sign in

Paste a GitHub access token. It stays in this browser and is sent only to GitHub.

How to create the token (once, 2 minutes)
  1. Open github.com/settings/personal-access-tokens/new.
  2. Name it "Website editor" and choose an expiry (90 days is a good choice).
  3. Under Repository access, pick Only select repositories and choose anand-ambastha.github.io.
  4. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else off.
  5. Click Generate token, copy it and paste it above.

Anyone with this token can change the site, so treat it like a password. Revoke it on GitHub if you lose a device.
